## 5. ВНИМАНИЕ СЛЕДУЮЩЕМУ АГЕНТУ (Важные нюансы)
- **Авито Qrator / hCaptcha**:
  - При запросах из дата-центров или с чистого headless-браузера Авито возвращает HTTP 429/302 с экраном верификации.
  - Для преодоления сделан модуль `auth_session.py`: пользователю достаточно один раз выполнить `py -m scrapers.avito.auth_session`, кликнуть галочку «Я не робот» в открывшемся окне, и сессия сохранится в `scrapers/avito/browser_profile/`. После этого headless-сбор идет без препятствий.
