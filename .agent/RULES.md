# 📜 .agent/RULES.md — Инженерная конституция и стандарты проекта

> Этот документ определяет технические стандарты, правила мультиагентного взаимодействия и архитектурные запреты.  
> Нарушение этих правил ломает работу других агентов и карается откатом изменений.

---

## 1. Правила мультиагентного сосуществования

1. **Никакого несанкционированного рефакторинга**:
   - Если существующий модуль (FastAPI роуты, компоненты React, модели SQLite) работает и проходит тесты — **запрещено** переписывать его на другие библиотеки просто «по вкусу» (например, менять Vite на Next.js или SQLite на MongoDB).
   - Любое крупное изменение архитектуры должно быть оформлено как ADR в `.agent/DECISIONS/`.
2. **Атомарность изменений**:
   - Каждый агент решает конкретную задачу текущего спринта. Не начинайте 5 задач одновременно.
3. **Обязательная передача смены (Handover)**:
   - В конце каждой сессии **всегда** создается файл в `.agent/HANDOVERS/`. Без отчета о сессии работа считается незавершенной.
4. **Контекстная точность**:
   - При генерации откликов, резюме и офферов разрешено использовать **только реальные данные** из директории `assets/` (стек, реальные кейсы, расценки). Запрещено выдумывать несуществующие факты.

## 2. Стандарты стека и кода

### Backend (Python)
- **Версия**: Python 3.12+ (асинхронный стиль: `async/await` для сетевых вызовов и API).
- **Фреймворк**: FastAPI + Pydantic v2.
- **База данных**: SQLAlchemy 2.0 ORM + SQLite (файл `job_machine.db`).
- **Сетевые запросы**: `httpx` (async) или `requests` (sync в фоновых воркерах).
- **Кодировка**: Строго UTF-8 (`encoding="utf-8"` при открытии любых файлов).
- **Обработка ошибок**: Запрещены «голые» `except: pass`. Ошибки обязаны логироваться с контекстом.

### Frontend (React & Web)
- **Стек**: Vite + React 18/19 + TypeScript + Tailwind CSS v4 + Lucide Icons.
- **Дизайн-система**: Тёмная инженерная тема (`#090d16` фон, `#0b0f19` карточки, акценты Cyan `#06b6d4`, Violet `#8b5cf6`, Emerald `#10b981`).
- **Плотность информации**: Интерфейс разрабатывается для профессионала (высокая информационная плотность, читаемые шрифты JetBrains Mono для цифр и статусов).
- **Коммуникация с API**: Через единый клиент `src/api.ts` с proxy на `/api` -> `http://127.0.0.1:8000`.

## 3. Правила AI-слоя (OpenRouter Engine)

1. **Модели по умолчанию**:
   - Быстрый скоринг и фильтрация: `deepseek/deepseek-chat` или `openai/gpt-4o-mini`.
   - Генерация персонализированных офферов: `anthropic/claude-3.5-sonnet`.
2. **Анти-клише (Anti-ChatGPT filter)**:
   - В сгенерированных откликах категорически запрещены штампы:
     - ❌ *«Здравствуйте! Меня зовут...»*
     - ❌ *«Я ознакомился с вашей прекрасной вакансией...»*
     - ❌ *«Я идеальный кандидат, потому что имею богатый опыт...»*
     - ❌ *«Буду рад плодотворному сотрудничеству!»*
   - Структура любого отклика: **Боль клиента в 1-м предложении $\rightarrow$ Точный пруф из наших кейсов с цифрой $\rightarrow$ Легкий CTA (демо / созвон на 15 мин)**.

## 4. Антибан и безопасность парсинга

1. **HeadHunter (hh.ru)**:
   - Лимит откликов: не более 150–180 в сутки.
   - Рандомизация задержек между запросами: от 4 до 15 секунд.
   - Обязательная эмуляция человеческих заголовков User-Agent.
2. **Telegram (Telethon)**:
   - Соблюдение Telegram FloodWait.
   - Писать в личку только тем контактам, которые явно указаны в тексте объявления.
   - Не спамить в закрытые сообщества.
