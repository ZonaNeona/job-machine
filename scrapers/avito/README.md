# 🕷 Модуль парсинга «Авито Работа» (`scrapers/avito/`)

## 🎯 Миссия модуля
Сбор прямых IT-вакансий и предложений о подряде/парт-тайме от владельцев малого и среднего бизнеса (SMB), которые публикуются на **Авито Работе** в обход дорогих корпоративных тарифов hh.ru.

---

## 🔍 Специфика источника
1. **Прямой контакт с ЛПР**: Вакансии часто размещают сами владельцы, генеральные директора или руководители отделов продаж/логистики.
2. **Формат сотрудничества**: Высокая готовность к подряду (ИП/самозанятость) без оформления в штат и уплаты 43% налогов.
3. **Целевой питч**: Retainer 80 000 – 90 000 ₽/мес под ключ.

---

## 🛡 Обход антифрод-защиты Авито (Qrator / PerimeterX)
Авито выдает `HTTP 429: Доступ ограничен: проблема с IP` при прямых серверных запросах.
Для боевой работы используются 3 подхода:

1. **Мобильный API (`m.avito.ru/api`)**:
   - Эмуляция мобильного клиента Android/iOS с заголовком `X-App-Version` и мобильным User-Agent.
2. **Playwright Stealth с сохранением профиля**:
   - Запуск через Chromium с плагином stealth и авторизованной сессией.
3. **Резидентские/Мобильные прокси РФ**:
   - Ротация домашних IP провайдеров (МТС, Мегафон, Ростелеком).
