# 🚀 JOBMACHINE HQ — Командный Пункт Лидогенерации

Интеллектуальный автоматизированный конвейер для привлечения высокочековых заказов на IT-разработку (LLM/ИИ, Telegram-боты, автоматизация бизнес-процессов) с персональным веб-интерфейсом управления.

---

## 🎯 Ключевые показатели системы
- **Целевая аудитория**: РФ и русскоязычные заказчики за рубежом (прямые фаундеры, стартапы, SMB).
- **Финансовая планка**: 5–7 постоянных клиентов по 80 000 – 90 000 руб./мес.
- **Целевой ежемесячный доход (MRR)**: ~510 000 руб.

---

## ⚡ Быстрый старт (Локально)

### 1. Настройка переменных окружения
Откройте файл `web-app/backend/.env` (или `web-app/.env`) и укажите ваш ключ **OpenRouter**:
```env
OPENROUTER_API_KEY=sk-or-v1-ваш_ключ_здесь
OPENROUTER_DEFAULT_MODEL=anthropic/claude-3.5-sonnet
OPENROUTER_SCORING_MODEL=deepseek/deepseek-chat
```

### 2. Запуск в 1 клик
Запустите скрипт:
```cmd
web-app\run_dev.bat
```
Скрипт автоматически запустит:
- **FastAPI Бэкенд**: http://127.0.0.1:8000 (Swagger документация: `/docs`)
- **Vite Веб-интерфейс**: http://localhost:5173

## 🖥 Возможности Командного Пункта (Экраны)

1. **Воронка лидов (Pipeline)**:
   - Переключение между **Канбан-доской** и **Таблицей высокой плотности**.
   - Статусы лидов: `Новый`, `Скоринг пройден`, `Оффер готов`, `Отправлен`, `Ответ получен 🔥`, `В переговорах`.
   - Быстрый поиск и фильтрация по источникам (hh.ru, Telegram, Хабр Фриланс, FL.ru) и тегам.

2. **Студия офферов (Offer Studio & Lead Inspector)**:
   - Клик по любой карточке открывает сплит-экран: слева — исходный текст вакансии, извлеченные боли и оценка Match Score; справа — сгенерированный ИИ отклик.
   - Выбор модели OpenRouter (Claude 3.5 Sonnet, DeepSeek V3, GPT-4o, Llama 3.1 70B).
   - Поле для ваших кастомных инструкций к офферу.
   - Кнопки: «Одобрить и отправить», «Скопировать», «Перевести в переговоры», «В архив».

3. **База знаний разработчика (Knowledge Base)**:
   - Управление вашим профилем, стеком и реальными кейсами с цифрами и пруфами.
   - ИИ использует эти данные для обоснования экспертности и генерации откликов без шаблонного "AI-душка".

4. **Параметры и настройки**:
   - Финансовый калькулятор (целевое число клиентов × ставка = целевой MRR).
   - Тумблеры антибана: обязательный ручной апрув перед отправкой, минимальный порог скоринга, Telegram-уведомления.
